# Java Finance Array Processing

Набор консольных упражнений по обработке массивов на финансовых примерах.

## Сценарии
- статистика выплат: сумма, минимум, максимум и среднее;
- вычисление 13% от значений массива;
- проверка условий для бонусных выплат.

## Технологии
Java, массивы, циклы, условные операторы, `java.util.Arrays`.

## Запуск
Требуется JDK. Запустите класс `FinanceModule` (исходный файл `src/Main.java`) в IntelliJ IDEA.

Учебные задачи с тестовыми значениями, не финансовый продукт.
